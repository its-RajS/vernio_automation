# UI PRINCIPLES

Theme:
Minimalist Professional SaaS

References:

- Linear
- Notion
- Stripe Dashboard
- Vercel Dashboard

Avoid:

- AI-style interfaces
- Neon gradients
- Excessive animations
- Glassmorphism
- Dashboard clutter

Design Rules:

- Large whitespace
- Clean typography
- Consistent spacing
- Simple navigation
- Fast interactions
- Shadcn-first components

The application should feel like an internal creative operations platform rather than an AI application.
